# Storage DOX - SurrealDB, Writes, Embeddings

## Purpose

Persistence, indexing, write lifecycle, embeddings, reranking providers, and read-your-writes overlay for operational recall.

## Ownership

- `surreal/**`: SurrealDB schema, stores, migrations, session turns, runir sessions, phase-2/noema/semiote persistence, continuity-state persistence (`continuity-state-store.ts`: `project_continuity_state` / `project_enrollment` / `continuity_build_state`, Rúnir-78sy.3), and continuity-gap persistence (`continuity-gap-store.ts`: `continuity_gap` / `continuity_gap_build_state` / `continuity_report_state`, Rúnir-78sy.4/78sy.5). **Rúnir-u7tn.1** split the former monofile `surreal-store.ts` into a re-export barrel plus: `surreal-client.ts` (`SurrealClient`, `extractId`, `mapMemoryRowToSearchHit`, shared constants/cache), `memory-schema-bootstrap.ts` (BM25/enrichment/attribution DDL), `memory-crud-store.ts` (upsert/list/get/delete/similar/supersede/lineage/health/archive/novelty), `session-watermark-store.ts`, `embedding-fingerprint-store.ts`, `supersede-shadow-store.ts`, `rejection-log-store.ts`, `project-state-store.ts`. Compat path `src/surreal-store.ts` remains `export *` from the barrel. Behavior-preserving only — do not rewrite SurrealQL planner-sensitive queries when moving code.
- `writes/**`: write arbitration, dedup/merge/supersede/create decisions, trace event emission. Façade is `write-arbitrator.ts` (pipeline + frozen re-exports). Leaf modules: `write-signals.ts` (tag/text signals + `mergeKeepBothReason`), `write-flags.ts` (env-flag readers), `referent-keys.ts` (`incomingReferentKeys`/`candidateReferentKeys`), `recent-writes.ts` (recent-cache helpers), `shadow-snapshots.ts` (`snapshotCandidate`/`snapshotRecentWrite`), `overlay-lifecycle.ts` (`OverlayHandle` + put/trace helpers), plus existing `referent-identity.ts`, `supersession-judge.ts`, `supersede-guards.ts`, `text-normalize.ts`, `overlay-supersession.ts`.

- `embeddings/**`: embedding client/provider abstraction; providers: `ollama-provider.ts`, `nomic-provider.ts`, `llamacpp-provider.ts` (OpenAI-compatible `/v1/embeddings`; env via `resolveEmbeddingProvider` in `src/shared/config.ts`).
- `reranking/`: reranker provider implementation.
